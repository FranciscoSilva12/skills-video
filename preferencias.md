# Preferências
- Rodar ffmpeg com `-hide_banner -loglevel error -stats` para poupar tokens.
- Usar sempre a skill caveman nível **lite** em toda sessão (sem enrolação, frases completas, português).
- Vídeo final sempre em qualidade máxima (x264 `-preset slow -crf 18`, Remotion `--crf=18`); prévias podem ser rápidas.
